# 秀知院大学 × 替身版时间线施工说明 v1.0

本目录以 `timeline/original/` 三季原卡时间线为只读母本，仅做轻量适配，不重写原剧情。

## 施工原则

1. 原卡日期、事件标题、事件顺序、核心因果、胜负与结局保持不变。
2. 高中语境只做大学化替换：
   - 秀知院学园 / 高中 → 秀知院大学；
   - 高中生恋爱调查 → 大学生恋爱调查；
   - 学校第一 → 年级综合成绩第一；
   - 留级危机 → 学分不足 / 升年级危机；
   - 走路上学 / 放学后 → 步行到校 / 课后；
   - 早会 → 全校集会；
   - 体育节 → 大学体育祭；
   - 三方面谈 / 志愿 / 直升 → 大学升学规划 / 研究生方向 / 内部升学；
   - 跳级前往海外 → 提前完成本科阶段并赴海外继续深造；
   - 初入高中 → 初入大学；
   - 文化祭 / 学园祭 → 大学奉心祭。
3. 学生会、社团、大学礼仪制服、校董会、校园建筑等在大学世界线中继续存在，不为了“更像现实大学”擅自删除原作舞台装置。
4. 替身节点只旁插，不覆盖原事件。原作事件仍然是恋爱喜剧主轴，替身是现实存在的第二层冲突与表现手段。
5. 已有人物条目中的 `替身觉醒契机` 优先级最高：
   - 若角色的潜在资质早在童年 / 过去事件中触发，本时间线不得把主线内一次显现误写成第二次“首次觉醒”；
   - 主线可记录“首次稳定具现 / 首次主动使用 / 首次被其他替身使者确认”。
6. 真正发生在本时间线期间、且与既有人物觉醒契机完全一致的情况，可以直接写“觉醒”。
7. 觉醒或显现不等于情绪阈值升级。情感只提供真实事件驱动力；能力仍服从对应替身原作机制与项目边界。
8. 本轮只加入少量关键节点，不要求30名替身使者全部在三季内逐一展示觉醒。
9. `timeline/original/` 永久保留原样，正式装配使用本目录大学替身版。

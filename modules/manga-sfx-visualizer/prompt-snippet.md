# 日漫拟声字演出协议（可选）

当且仅当场景出现明显的漫画式“视觉冲击瞬间”时，可以在相关正文之后追加一个不可见 HTML 注释，交给可选的日漫拟声字视觉插件播放。

允许使用：

```html
<!--SFX:impact|ドン！！-->
<!--SFX:rumble|ゴゴゴゴゴ……-->
<!--SFX:shock|ガーン！-->
```

使用规则：

1. 普通对话不要触发；不要为了“有特效”而强行制造特效。
2. 单次回复建议 0～2 个，极端高潮最多 3 个。
3. `impact` 用于重击、战吼、强势断言、突然登场。
4. `rumble` 用于心理战、威压、杀气、空气凝固般的压迫。
5. `shock` 用于震惊、破防、社死、计划瞬间崩盘。
6. 拟声字保持短促，优先使用日漫常见的片假名拟声，不写长句。
7. HTML 注释只是演出指令，不要在正文中解释它，不要把它当作角色台词。
8. 没有安装插件时这些注释应保持不可见，因此正文必须自身完整、可读、可理解。

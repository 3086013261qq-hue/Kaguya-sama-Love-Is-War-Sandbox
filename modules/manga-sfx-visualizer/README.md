# 日漫拟声字视觉插件（Manga SFX Visualizer）

版本：v0.1.0  
定位：**完全可选的 Tavern Helper / 酒馆助手视觉增强脚本**。

它只负责一件事：当新的角色回复中出现隐藏的 SFX 演出指令时，在 SillyTavern 主界面短暂弹出日漫式拟声字。

## 不会做什么

- 不修改角色卡正文
- 不修改世界书
- 不修改 MVU
- 不写聊天记录
- 不写变量
- 不联网（源码本身无网络请求；若使用导入 JSON，仅在加载脚本源码时通过 jsDelivr 读取本仓库固定版本）
- 不要求角色卡依赖它才能运行

不安装本插件时，推荐协议使用 HTML 注释，浏览正文时不会看到任何脏标签。

## 安装

1. 安装并启用酒馆助手（Tavern Helper / JS-Slash-Runner）。
2. 在酒馆助手的「脚本库」中导入：
   `日漫拟声字视觉插件_v0.1.0.json`
3. 确认脚本已启用。
4. 点击脚本按钮 **「拟声字预览」**。
5. 若依次看到「ドン！！」「ゴゴゴゴゴ……」「ガーン！」，说明视觉层正常工作。

建议作为**全局脚本**安装；如果只想给某一张卡用，也可以导入角色脚本库。

## 推荐触发协议

在 AI 回复中加入不可见 HTML 注释：

```html
<!--SFX:impact|ドン！！-->
<!--SFX:rumble|ゴゴゴゴゴ……-->
<!--SFX:shock|ガーン！-->
```

支持的三种演出：

- `impact`：中央猛然弹出，适合重击、战吼、断言、登场。
- `rumble`：右侧纵向压迫字，适合气场、心理战、威压。
- `shock`：从上方砸落，适合震惊、破防、社死。

兼容别名：

- `warcry` → `impact`
- `pressure` → `rumble`

也兼容旧式写法：

```html
<sfx type="impact">ドン！！</sfx>
```

但旧式写法在未安装插件时可能被正文渲染器处理，因此**正式内容推荐 HTML 注释协议**。

## 约束

- 单条消息最多播放 4 个拟声字。
- 单个拟声字最多读取 24 个字符。
- 仅监听新收到的 assistant 消息，不会在刷新页面时把整段历史重新放一遍。
- 视觉节点使用 `textContent` 写入，不执行拟声字中的 HTML。
- 动画层 `pointer-events:none`，不会挡住聊天、输入框和按钮。
- 遵循系统 `prefers-reduced-motion` 设置，减少动画时会自动缩短演出。

## 给模型的可选提示词

见 `prompt-snippet.md`。

如果不加入提示词，插件不会强制改变模型写法；只有收到 SFX 指令时才演出。

# 内生世界描述净化审计 v1.0

## 审计目标

确保正式 Character Book 只向模型提供世界内部事实，不注入项目来源、改编过程、迁移说明、施工要求或QA备注。

## 本轮处理

1. `worldbook/core/000_秀知院大学世界线总则.md`
   - 删除“平行世界沙盒、原作映射、旧母卡、运行时回退”等制作层表述。
   - 重写为秀知院大学的客观学校、年龄、年级、学生会、升学与世界规律。

2. `worldbook/core/001_秀知院大学礼仪制服与校园制度.md`
   - 删除“兼容规则、原卡视觉锚点、统一迁移”等制作层表述。
   - 重写为秀知院大学本身存在的礼仪制服、学生自治、学园祭与大学运动会制度。

3. `worldbook/final/assemble_worldbook.py`
   - 最终输出名称改为 `辉夜大小姐_秀知院大学_character_book_v1.0.json`。
   - 最终 description 改为纯世界内描述。
   - 人物条目组装时删除 `世界线:...` 行。
   - `年龄:xx岁（成年人）` 统一输出为 `年龄:xx岁`。
   - Entry 56 重写为纯内生的大学学籍与年级规则。
   - Entry 57 去除外部作品参考、BadEnd/玩家等游戏化说明，改为世界内的极端关系崩坏规则。
   - Entry 61 去除“作品/原作/AU/迁移/运行时过滤器”等措辞，改为世界内部的现代现实规律、头脑战主观感受与恋爱社交逻辑。
   - Entry 81 的编辑器注释改为 `局部变量初始化`。
   - 时间线 comment 中删除 `(多选一)` 制作提示。
   - 加入正式输出泄漏检测，发现以下制作层标记时直接拒绝构建：`授权母卡 / 旧母卡 / 原卡 / 原作 / 本世界书 / 正式运行 / 运行时 / 升学重映射 / 自动迁移 / 秀知院大学AU / （成年人）`。

4. `worldbook/core-rules/original_core_rules.md`
   - 该文件属于原卡拆解的重复副本，不参与正式世界书。
   - 原始母数据已在 `source/` 留档，因此从 `worldbook/` 删除，避免后续误装。

5. `worldbook/final/manifest.json`
   - 正式名称改为 `辉夜大小姐想让我告白 - 秀知院大学 v1.0`。
   - runtime output 明确为 `辉夜大小姐_秀知院大学_character_book_v1.0.json`。
   - 增加 `runtime_text_policy: in-world-only`。
   - 83条 Entry、ID 0–82、默认时间线 Entry 74 与模块顺序保持不变。

## 不改动项

- Entry 数量：83
- Entry ID：0–82
- insertion_order
- enabled / constant
- position / depth
- regex keys
- 三季时间线事件顺序与日期
- 第一季·上 Entry 74 的默认启用状态
- 人物性格、关系、身体数据、对话范例与剧情事实

- STATIC_STRUCTURE_QA: PASS

- SOURCE_ARCHIVE_PRESERVED: PASS

# 010｜蓝灯05设定层绿灯查漏补缺 v1.0

## 审核对象
蓝灯05｜情感能源法则

本轮只审核并展开蓝灯05下的世界设定层绿灯，不涉及人物卡、地点、时间线、输出规则、运行时机制与具体角色替身分配。

## 原卡继承情况
原卡没有“情感作为替身唯一能源”的设定层绿灯，因此蓝灯05不存在可直接继承的旧绿灯。

本轮严格以当前项目已经冻结的核心为基础：

**真实情感是替身唯一驱动力。**

不引入：
- 觉悟值
- 决意值
- 精神力
- 意志值
- 魔力/法力
- 情感纯度
- 情绪等级
- 固定倍率
- 储能槽或独立能量池

## 本轮正式绿灯

### 绿灯05-01｜复合情感与主导情绪
路径：
`worldbook/green/05_情感能源/001_复合情感与主导情绪.md`

覆盖：
- 多种真实情感同时存在
- 爱意、羞耻、嫉妒、恐惧、愤怒、期待、占有欲、安心、性欲等复合情绪
- 同一情感面对不同对象时拥有不同重量
- 当前最强烈、最集中的情感形成主导情绪
- 主导情绪随局势变化
- 其他较弱情感继续存在并影响判断
- 情感协调与情感冲突对替身发挥、控制与战斗节奏的不同影响

重要边界：
复合情感只描述人物此刻真实存在的情绪结构，不建立“纯度”“权重数值”“情绪槽”等额外计算系统。

替身能力本身继续保持固有规则；复合情感改变的是现有能力如何被发挥、集中和控制。

### 绿灯05-02｜情感持续、压抑与消退
路径：
`worldbook/green/05_情感能源/002_情感持续压抑与消退.md`

覆盖：
- 短时情绪高峰
- 长期爱意、执念、遗憾、孤独、恐惧、保护欲与占有欲
- 情感退居背景后继续存在
- 嘴硬、否认、转移话题、自我说服与刻意回避
- 被压抑感情在相关人物、记忆或事件出现时重新浮现
- 情感随时间、距离、关系变化、新信息与生活经历逐渐减弱、加深或转化
- 长期稳定情感与短时爆发情绪对替身状态的不同影响

重要边界：
“压抑”不等于把情感存进独立能量池。被压抑的感情仍然以感情本身存在；它重新浮现时，替身响应的是人物当下真实重新感受到的情绪。

## 与蓝灯06的职责边界
蓝灯05及其绿灯负责：
- 情感本身是什么
- 多种情感如何共存
- 哪一种情感成为主导
- 情感如何持续、被压抑、淡化或转化

蓝灯06及其后续绿灯负责：
- 外界刺激怎样改变情感
- 语言、亲密接触、误会、环境、成人情趣刺激等如何放大或改变情绪
- 情绪增幅的战术使用、误判与反噬
- 自主与同意边界

两者关系为：
**05描述情感内部结构，06描述外部刺激如何推动这套结构发生变化。**

## 查漏判断

### 是否需要新增“情感纯度”独立绿灯：NO
当前项目以真实性、强烈程度、持续时间与集中程度共同描述情感强度。引入“纯度”会额外建立第二套判断标准，并造成“爱更纯所以更强”之类不必要的层级化。

### 是否需要新增“情感数值/倍率”绿灯：NO
设定层保持自然语言状态，不把情感机械化成数值槽、固定倍率或统一公式。后续若MVU需要显示状态，只能作为表现层，不反过来定义世界规律。

### 是否需要新增“情感对象绑定”绿灯：NO
蓝灯05及绿灯05-01已经说明同一种情感面对不同对象拥有不同重量，当前注意力与真实在意对象会影响替身状态；无需单拆。

### 是否需要新增“压抑储能”绿灯：NO
长期压抑属于持续存在的真实感情，不形成独立储能机制。突然爆发来自“长期持续 + 瞬间集中”的共同作用。

## 蓝灯05当前正式绿灯
1. 绿灯05-01｜复合情感与主导情绪
2. 绿灯05-02｜情感持续、压抑与消退

两条分别覆盖：
- 情感的横向结构：多种情绪如何同时存在与争夺主导
- 情感的纵向结构：一份感情如何随时间持续、压抑、变化与消退

与蓝灯05共同形成“真实情感 → 复合结构 → 主导情绪 → 持续/压抑/转化 → 替身发挥”的完整情感能源结构。

# 004｜JOJO替身原著灵魂与九条蓝灯拉通审计 v1.0

## 审计目标
对当前《辉夜大小姐想让我告白》替身化九条蓝灯进行拉通审核：

1. 保留《辉夜大小姐想让我告白》的成年大学校园、恋爱喜剧、头脑战、阶层与人物关系底盘。
2. 对照《JOJO的奇妙冒险》替身体系的核心通则，检查是否把替身写成普通“超能力系统”。
3. 区分必须常驻的蓝灯灵魂与应下沉到绿灯/人物条目的具体机制。
4. 检查旧构建层是否仍存在与新世界观直接冲突的规则。

## 审计结论

### BLUE_LIGHT_SKELETON：PASS
当前九条蓝灯数量与职责足够，不新增第10条蓝灯。

九条职责保持：
1. 世界基调｜天才们的恋爱战争
2. 学籍、年龄与校园身份法则
3. 现实社会、财富与阶层法则
4. 替身存在与替身使者法则
5. 情感能源法则
6. 情感波动与增幅法则
7. 替身适配与觉醒法则
8. 颅内剧场即替身战法则
9. 恋爱头脑战与表白原则

### KAGUYA_CORE：PASS
- 日常、恋爱、友情、学生会、社团、家庭、阶层与未来规划仍是剧情主体。
- “恋爱是一场战争”仍是世界核心气质。
- 替身不是另起一套动作番，而是把原本的心理攻防真正外显成战斗。
- 表白不是机械判负，而是情报暴露、情感峰值、关系选择与战术风险同时发生。
- 固定柴刀/强制极端结局不属于本世界核心。

## JOJO核心灵魂核对

### 1. 替身是人的精神与人格外显：PASS
蓝灯04与07已强化：替身不是装备或随机技能，而是与人格、经历、欲望、恐惧、执念和内在结构长期绑定的超常精神表现。

### 2. 普通人通常看不见替身：PASS
蓝灯04保留普通人不可直接看见替身，只能看见其现实后果；特殊可见/物质化类型服从自身固有规则。

### 3. 通常只有替身能直接对抗替身：FIXED → PASS
本轮补入蓝灯04：普通拳脚、刀具、枪械等通常不能直接伤害替身本体；替身之间或符合固有特殊规则的能力才能有效作用。物质化、依附实体等例外服从各自规则。

### 4. 替身受创与本体通常存在伤害反馈：FIXED → PASS
本轮补入蓝灯04：多数替身遭受有效伤害会反馈本体，替身被彻底破坏通常意味着本体遭受致命后果；自动型、物质化、依附型、死后持续型等例外不强行统一。

### 5. 替身形态与行为高度多样：FIXED → PASS
本轮补入蓝灯04：替身不默认等于人形守护灵，可为人形、非人形、物体依附、群体、现象、自动行动等；多数服从本体，但少数具有独立意识、自动逻辑或难以控制的特性。

### 6. 一人通常一个核心替身：PASS
蓝灯07已明确，一人通常只有一个核心替身；ACT、复数形态、分体、共享、寄宿、转移等只能按该替身原有规则发生。

### 7. 替身使者相互吸引：PASS
蓝灯04已将其写成“命运对相遇概率的偏转”，而非雷达定位或强制关系生成；只制造相遇，不制造爱情、友情或敌意。

### 8. 情感是唯一驱动力：PASS
蓝灯05明确：替身的可调用力量只由真实情感驱动，不引入“觉悟”“决意”“精神力”“意志值”等第二层能源或中间变量。

JOJO叙事中常见的坚定、决心、拼死一搏等表现可以自然出现在人物行动里，但它们不参与替身强弱判定，也不构成独立机制。人物是否愿意行动，是人物选择；替身当前能够发挥多强，只看实际存在的情感。

### 9. 能力规则、限制与解谜比纯面板更重要：FIXED → PASS
本轮补入蓝灯08：替身战默认存在能力未知、条件未知、射程未知、媒介未知与本体位置未知；需要观察、试探、推理、诱导和实战确认。能力一旦确立不得临时改写。

### 10. 本体仍是弱点：FIXED → PASS
本轮补入蓝灯08：替身强不等于本体无敌。寻找本体、脱离射程、切断媒介、破坏发动条件、制造错误目标等均为合法战术思路。

### 11. 觉醒不是“情绪够高自动送替身”：FIXED → PASS
本轮补入蓝灯07：情绪高峰可以成为契机，但必须存在替身资质；才能磨炼、人生经历、强力替身事件或特殊外部契机也可影响觉醒。单纯情绪强烈不会无条件创造替身。

## 有意保留的项目改造
以下内容与JOJO常规设定不同，但属于本项目已经冻结的核心设计，不视为缺陷：

- 替身的可调用力量统一以“真实情感”为唯一能源，不另设生命能量、精神力、魔力值、觉悟值或决意值。
- 爱意、羞耻、嫉妒、恐惧、愤怒、情欲、性欲、保护欲、执念等均可供能。
- 情感是否被承认、是否被嘴硬掩饰，不改变它是否真实存在；真实存在的情感就会影响替身。
- 原本《辉夜》式颅内法庭、棋盘、战争与审判，在替身介入时直接成为真实替身战表现层。

## 应下沉到绿灯/人物条目的JOJO机制
以下内容不升蓝灯，以免常驻上下文膨胀：

- 六维参数：破坏力、速度、射程距离、持续力、精密动作性、成长性。
- 近距离力量型、远距离型、自动操纵型、群体型、依附型、物质化型、死后持续型等详细分类。
- 射程与精度/力量之间的常规取舍及各替身例外。
- 特殊感知、共享视觉、缩小、穿透物体等非所有替身共有的技巧。
- ACT、特殊进化、特殊媒介赋予、寄宿、转移、共享、死后持续等个别机制。
- 具体替身的能力说明、触发条件、弱点、参数、喊声与表现方式。
- 每名《辉夜》角色具体适配哪一个替身。

## 构建层冲突检查

### CURRENT_ASSEMBLER_CONFLICT：BLOCKER
当前 `worldbook/final/assemble_worldbook.py` 仍保留旧构建覆盖：

- `EXTREME_RELATIONSHIP_RULE`：仍会生成旧的“关系崩坏极端结局”条目。
- `WORLD_RULE`：仍明确写着“不存在超自然力量”，并把棋盘、刀光剑影、审判庭等限定为主观心理意象。

这两项与现已封版的蓝灯04、08、09直接冲突。

结论：
- 当前 `worldbook/core/` 九条蓝灯源文件可以继续作为正式设定源。
- 在蓝灯/绿灯内容完成并正式接入 `worldbook/final/` 前，旧 assembler 不得用于生成候选世界书。
- 后续正式集成时必须删除旧关系崩坏覆盖、替换旧现实主义过滤规则，并把新蓝灯按咩咩全栈格式接入最终世界书。

# 011｜蓝灯08设定层绿灯查漏补缺 v1.0

## 审核对象
蓝灯08｜颅内剧场即替身战法则

本轮只审核并展开蓝灯08下的世界设定层绿灯，不涉及人物卡、地点、时间线、输出规则、运行时机制与具体角色替身分配。

## 原卡可继承素材
来源：原卡核心规则 ID 61 中的恋爱头脑战夸张演出体系。

可继承内容包括：
- 脑内法庭与脑内会议
- 棋盘、棋子与Checkmate
- 刀光剑影、箭矢贯心、爆炸与压迫景象
- 雷达锁定、战略地图与包围网
- 日常小动作与宏大心理战同时发生
- 第三者或意外变量突然打乱原有头脑战结构

旧版将这些表现理解为纯心理视觉隐喻；当前世界中，它们已经被蓝灯08正式改造为替身介入时真实存在的战斗感知层。

原卡中针对藤原千花的“混沌干扰”属于具体人物表现，不作为通用设定直接写入绿灯；本轮只继承“第三者介入会重排战局”的普遍规律。

## 本轮正式绿灯

### 绿灯08-01｜颅内剧场表现层与现实映射
路径：
`worldbook/green/08_颅内剧场即替身战/001_颅内剧场表现层与现实映射.md`

覆盖：
- 法庭、审讯、棋盘、战争、追猎、箭矢、刀剑、爆炸、雷达、Checkmate等表现
- 日常现实动作与替身战同时发生
- 普通人主要感知现实层结果
- 替身使者同时读取现实行为、替身动作、情绪与能力现象
- 第三者、意外事件与新情报导致战局重排

重要边界：
颅内剧场负责提供战斗表现层，不负责凭空产生新能力。真正的伤害、束缚、移动、时间变化、感知异常及其他超常效果，始终来自参与者各自替身的固有能力。

### 绿灯08-02｜能力解谜与情报战
路径：
`worldbook/green/08_颅内剧场即替身战/002_能力解谜与情报战.md`

覆盖：
- 从现象反推能力规则
- 建立假设并通过改变条件进行试探
- 发动条件、射程、媒介、目标、限制与弱点的逐步确认
- 故意伪装、隐藏条件、错误诱导与假弱点
- 核心能力规则稳定，新用法沿既有逻辑开发
- 使用者习惯、本体位置、保护对象与情感软肋也属于战术情报

重要边界：
看见替身并不会自动知道能力；替身使者也不会天然读取对方真实内心。判断依赖现场证据、关系信息、观察、试探与推理。

### 绿灯08-03｜本体、媒介与发动条件攻防
路径：
`worldbook/green/08_颅内剧场即替身战/003_本体媒介与发动条件攻防.md`

覆盖：
- 本体距离、伤势、疲劳、视野与行动自由
- 物品、地点、声音、影像、接触与其他能力媒介
- 发动条件与维持条件
- 射程、环境、视线、路线与旁观者
- 找本体、切媒介、脱离射程、破坏条件、保护目标等战术
- 替身战通过达成目标、解除能力、撤离危险、取得情报等方式结束

重要边界：
该条描述的是单场替身战如何形成战术胜负，不定义恋爱关系中的最终胜负。恋爱主动权、表白、真心暴露与“谁先表白谁就输”继续由蓝灯09及其绿灯负责。

## 与其他蓝灯的职责边界

### 与蓝灯04
- 蓝灯04与其绿灯负责替身的基础存在、六维、类型、射程与本体伤害反馈。
- 蓝灯08负责如何利用这些已知性质进行实际战斗、推理与条件破解。

### 与蓝灯05、06
- 蓝灯05、06负责真实情感本身及其增幅。
- 蓝灯08只把情感变化作为战斗信息、诱导因素与战术变量使用，不建立新的情感规则。

### 与蓝灯09
- 蓝灯08负责替身战的局部胜负与战术达成。
- 蓝灯09负责恋爱头脑战、表白、主动权与关系层胜负。

## 查漏判断

### 是否需要新增“第三者混沌干扰”独立绿灯：NO
第三者扰局已经由绿灯08-01作为通用战斗规律覆盖。藤原千花等具体人物如何制造混沌，应由人物条目与其具体替身承担。

### 是否需要新增“视觉特效词库”独立绿灯：NO
原卡法庭、棋盘、雷达、箭矢、刀剑、爆炸、战略地图等素材已经由08-01完整继承；继续拆分只会形成表现词库而不是世界设定。

### 是否需要新增“胜负判定”独立绿灯：NO
08-03已经说明替身战可以通过解除能力、破坏条件、保护目标、脱离射程与取得决定性情报等方式形成实际胜负。恋爱关系胜负另归蓝灯09。

## 蓝灯08当前正式绿灯
1. 绿灯08-01｜颅内剧场表现层与现实映射
2. 绿灯08-02｜能力解谜与情报战
3. 绿灯08-03｜本体、媒介与发动条件攻防

三条分别覆盖：
- 头脑战如何获得真实战斗表现层
- 未知能力如何被观察、试探与破解
- 替身战如何围绕本体、媒介、条件与环境推进

与蓝灯08共同形成“现实动作 → 战斗表现层 → 能力未知 → 推理试探 → 条件破解 → 战术结果”的完整替身头脑战结构。

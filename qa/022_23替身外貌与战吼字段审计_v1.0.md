# 022 23替身外貌与战吼字段审计 v1.0

## 目标

对当前23名正式替身使者的独立能力条目补齐并审计：

- `替身外貌`
- `战吼`

字段直接写入既有 `<角色名ability>` 条目，不新增第二套能力绿灯，不修改人物正文。

## 1. 格式

统一顺序：

```text
角色: ...
替身: ...
[版本 / 附属能力 / 潜在进化等既有字段]

```

[PASS] 四批能力条目均已补充外貌与战吼字段。
[PASS] 人物character条目未因此增加字段或重复能力说明。
[PASS] 未新增平行能力文件，避免额外Token与绿灯触发。

## 2. 外貌原则

- 只继承JOJO正传对应替身的稳定造型锚点。
- 不因《辉夜大小姐想让我告白》角色成为新使用者而给替身换装、性转、重绘或增加人物专属装饰。
- 不把漫画彩页、动画、游戏之间可能变化的配色写成唯一绝对官方色。
- 无独立实体外貌时如实记录媒介形态。

特殊例：

- Paper Moon King：无独立实体本体，以折纸造物显现。
- Yellow Temperance：无定形物质，外观随伪装变化。
- Hermit Purple：藤蔓型，无独立人形本体。
- Harvest / Pearl Jam：复数微型单位。
- Wonder of U：同时记录机械真身与明负悟人类伪装。
- Paisley Park：记录早期二维/影子形态与后期三维人形特征。
- THE MATTEKUDASAI：记录机械鸟类默认形态与可变尺寸。

## 3. 战吼原则

### 明确固定连打/攻击战吼

- 白银御行 / Crazy Diamond：`DORARARA...!`
- 早坂爱 / Star Platinum：`ORA ORA ORA...!`
- 白银父 / The World：`MUDA MUDA MUDA...!`
- 四条真妃 / Soft & Wet：`ORA ORA ORA...!`；初次连打曾出现`ORA ORA ARA ORA...!`
- 四宫辉夜 / JoJolion Killer Queen：`WRYYYYYEEEEAH!`

### 有能力叫声/会话，但不是固定连打战吼

- 四条帝 / THE MATTEKUDASAI：无固定连打战吼；能力发动时常见`NYUUUUN / NYUUUMU`，并可说`MATTE KUDASAI`。
- 巨濑绘理香 / Pearl Jam：无固定连打战吼；显现/被发现时有`meshaa!`类短促叫声。
- 田沼翼 / Hey Ya!：无固定战吼；主要通过直接语言持续鼓励、提醒使用者。
- 纪加莲 / Heaven's Door：无固定战吼；使用者可喊能力名发动，但不等同于替身固定连打音。

### 无固定战吼

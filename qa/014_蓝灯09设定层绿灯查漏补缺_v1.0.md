# 014｜蓝灯09设定层绿灯查漏补缺 v1.0

## 审核对象
蓝灯09｜恋爱头脑战与表白原则

本轮只审核并展开蓝灯09下的世界设定层绿灯，不涉及人物卡、地点、时间线、输出规则、运行时机制与具体角色替身分配。

## 原卡可继承素材
原卡核心规则 ID 61 中存在大量“恋爱头脑战”素材，可转化部分包括：
- 自尊心与主动权竞争
- 语言试探与行为暗示
- 诱导对方先暴露真心
- 误会、装傻、假弱点与社会性尴尬
- 一句普通对话背后的多轮心理攻防

旧 ID 61 中“绝对现实主义”“禁止超自然”“所有战斗只是心理比喻”等内容已被当前替身世界观彻底替代，不再继承。

## 本轮正式绿灯

### 绿灯09-01｜先后手、诱导与情感暴露
路径：
`worldbook/green/09_恋爱头脑战与表白原则/001_先后手诱导与情感暴露.md`

覆盖：
- 先手与后手的动态交换
- 邀约、话题、距离与场景选择带来的主动权
- 迂回邀约、假设性问题、第三者试探与普通社交包装
- 假弱点、假退让、故意冷淡与顺势反诱导
- 从言行、消息回复、替身反应与情绪波动推测真实在意
- 情感暴露与正式表白之间的区别
- 真正表白必须来自人物主动承认真实感情并愿意承担回应与后果

重要边界：
被迫重复“喜欢”、为了脱困而配合的台词、误导性暧昧表达或失去自主选择时的发言，不会自动形成真实表白。

### 绿灯09-02｜多层胜负与关系后果
路径：
`worldbook/green/09_恋爱头脑战与表白原则/002_多层胜负与关系后果.md`

覆盖：
- 情报层胜负
- 主动权层胜负
- 替身战层胜负
- 面子与自尊层的小胜负
- 真心暴露与关系推进
- 表白后的重新解释、接受、拒绝、沉默与协商
- 长期信任、秘密、伤害与关系阶段变化

重要边界：
“谁先表白谁就输”首先是一种关于主动权、自尊与底牌暴露的秀知院恋爱心理逻辑。

先表白可以在“谁先暴露”这一层被视为失败，却在“关系终于向前”这一层形成决定性成功。它不会自动导致关系破裂、恋爱失败，也不会决定谁永久失去主动权。

## 与蓝灯08的职责边界
蓝灯08及其绿灯负责：
- 替身战怎样进行
- 能力规则怎样推理
- 本体、媒介、发动条件怎样被攻防
- 一场具体替身交锋怎样结束

蓝灯09及其绿灯负责：
- 恋爱中为什么争夺先手
- 怎样诱导对方暴露感情
- 表白为什么会交出重要情报
- 为什么战斗层、面子层、信任层与关系层可能出现不同胜负
- 表白后关系怎样继续发展

因此：
**08处理“这一场战怎么赢”，09处理“这场恋爱攻防的胜负究竟意味着什么”。**

## 与蓝灯05/06的职责边界
蓝灯05负责真实情感本身的结构；蓝灯06负责外界刺激如何推动情绪；蓝灯09则负责人物怎样在恋爱关系中利用、隐藏、暴露和承认这些真实情感。

诱导只能制造情境、信息与刺激条件，不能替代人物真实感情与自主选择。

## 查漏判断

### 是否需要新增“表白自动胜负判定”绿灯：NO
不存在自动判定。表白的意义来自真实感情暴露、主动权变化、对方回应与关系后续。

### 是否需要新增“恋爱数值/好感度”绿灯：NO
人物关系继续由实际相处、信任、行为、选择与真实感情形成，不引入统一数值作为世界规律。

### 是否需要新增“强制BadEnd/柴刀结局”绿灯：NO
原卡 ID 57 已明确删除。出轨、背叛、欺骗、伤害与越界会按人物性格和真实关系产生对应后果，但不存在统一强制结局。

### 是否需要把所有恋爱战术逐条拆绿灯：NO
常见诱导、试探、假弱点与先后手逻辑已经由绿灯09-01覆盖。具体角色如何使用，应由人物性格、关系与具体替身能力决定。

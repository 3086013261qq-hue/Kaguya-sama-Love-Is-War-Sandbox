# Kaguya-sama: Love Is War Sandbox

《辉夜大小姐想让我告白》角色卡 / 世界书 / 时间线 / MVU 独立工程仓库。

## 当前正式世界线

本工程采用独立的 **“秀知院大学世界线”**：主舞台由高中整体迁移至大学，所有具名学生角色均为成年人（最低 18 岁）。原作初三→大一、高一→大二、高二→大三、高三→大四；原作考大学/志愿校/升学剧情整体迁移为考研、研究生院志愿、推免、就业与留学规划。

原作人物性格、关系、恋爱喜剧机制、家族背景、事件因果和对话风格尽量保留；凡依赖高中、初中或未成年身份的表述，在派生内容中统一按大学世界线改写。最高迁移规范见 `docs/002_秀知院大学世界线迁移规则_v1.0.md` 与 `worldbook/core/000_秀知院大学世界线总则.md`。

## 工程原则

- 唯一正式分支：`main`
- 保留原始授权角色卡作为母版输入，不覆盖、不破坏原文件
- 后续施工优先采用：原卡拆解 → 基线冻结 → 世界书/人物/地点/时间线精修 → MVU → QA → 正式卡装配
- 不从零重造已经成熟且可复用的咩咩制卡结构
- 任何重大结构调整先留施工记录与 QA
- `source/` 与 `*/original/` 保存母卡事实；正式运行时采用大学世界线派生内容，不直接修改母版

## 来源与授权说明

本工程基于“咩咩”制作的《辉夜大小姐想让我告白》PNG角色卡继续整理与扩展。用户已说明其已取得该原卡的使用/改编授权。本仓库仅记录该来源与用户提供的授权状态，不将其表述为第三方可验证的正式授权凭证。

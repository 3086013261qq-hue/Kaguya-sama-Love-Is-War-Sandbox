## 2. 本轮冻结范围

### 2.1 世界规则

- `worldbook/core/`：9 条蓝灯，职责冻结。
- `worldbook/green/`：34 条绿灯，职责冻结。
- 蓝灯保持全局底层事实；绿灯保持按场景触发的展开规则。
- 禁止在总装配时将绿灯重新并回蓝灯，禁止因方便触发而扩大蓝灯常驻正文。

### 2.2 人物与替身

- 当前最终具名角色总数：44。
- 当前正式替身使者：30。
- 当前非替身使者：14，继续继承大学世界线人物源。
- `characters/stand-augmented/`：30名替身使者的角色增强覆盖层。
- `characters/stand-abilities/`：30名替身使者对应的独立能力条目。
- 人物本体与能力必须继续拆成独立世界书条目；不得在装配时重新合并。
- `stand-augmented/` 不是全体人物名单：最终角色区必须先构造完整44人集合，再以增强版覆盖对应30人，其余14人保留大学版正文。
- 高阶形态与特殊进化条件保持现有锁定，不得由装配器提前解锁。

### 2.3 地点

- `locations/university_locations.md` 为大学世界线正式地点事实源。
- 原高中措辞、旧母卡地点只可作历史资料，不得重新回灌正式运行时正文。

### 2.4 时间线

- `timeline/university-stand/season1_university_stand.md`
- `timeline/university-stand/season2_university_stand.md`
- `timeline/university-stand/season3_university_stand.md`

三季大学替身版时间线为正式时间线输入。时间线正文必须保持完整 `<world_timeline>` 结构，不因装配拆成事件碎片。

### 2.5 原卡保留层

`source/`、`timeline/original/` 与旧 `worldbook/final/` 83 条模块仅保留为母版事实、历史产物与迁移参考，不再作为本轮正式 Character Book 的直接运行时成品。

## 3. 正式装配技术口径

本轮统一采用：

- 咩咩制卡·全栈 v1.0.0
- chara_card_v3
- 内嵌 `character_book`
- ccv3 snake_case 字段
- 不修改咩咩预设本体

### 3.1 全栈七分区骨架

最终 Character Book 必须保留全栈母版七组分区，每组起始/结尾各一次，共14个空标记：

1. `【记忆相关:起始】` / `【记忆相关:结尾】`
2. `【输出规则:起始】` / `【输出规则:结尾】`
3. `【核心规则:起始】` / `【核心规则:结尾】`
4. `【核心设定:起始】` / `【核心设定:结尾】`
5. `【主要角色:起始】` / `【主要角色:结尾】`
6. `【其他角色:起始】` / `【其他角色:结尾】`
7. `【地点:起始】` / `【地点:结尾】`

不得因为本卡结构较轻而删除分区骨架，也不得重复创建已有分区标记。

### 3.2 咩咩记忆基础设施

最终整卡不得漏装母版记忆基础设施：

- `🗑️清空局部变量(别关)`：enabled=true、constant=true、selective=false、position=before_char、insertion_order=556。
- `【记忆相关:起始】`：enabled=true。
- `日常记忆存储`：默认 disabled。
- `重大记忆存储`：默认 disabled。
- `玩家身世背景`：默认 disabled。
- `【记忆相关:结尾】`：enabled=true。

清空局部变量条目使用咩咩母版变量名，不自造长期变量：

```text
{{setvar::combat_driver::}}
{{setvar::status_format::}}
{{setvar::世界书重大记忆存储::}}
{{setvar::世界书日常记忆存储::}}
{{setvar::世界书玩家身世背景::}}
```

三个记忆存储占位保持关闭，不因本卡存在 MVU 而擅自启用，也不接入另一套自造 schema。

### 3.3 字段硬规则

- 禁止 `preventRecursion / excludeRecursion / displayIndex / scanDepth` 等 camelCase 同义字段与 snake_case 并存。
- 使用 `prevent_recursion / exclude_recursion / display_index / scan_depth` 等母版字段。
- 条目顺序、`display_index`、`position`、`depth`、`enabled` 必须由装配 QA 校验。
- entries 数组顺序必须与全栈阅读顺序一致，不允许因排序/序列化把阅读顺序反转。

### 3.4 蓝灯 / 绿灯递归规则

#### 蓝灯：9条

蓝灯进入 `【核心规则】` 区：

- `constant=true`
- `selective=false`
- `keys=[]`
- `secondary_keys=[]`
- `position=after_char`
- 概率100
- 无关键词触发
- `prevent_recursion=false`
- `exclude_recursion=false`

蓝灯是常驻底层世界规则，不套绿灯的双防递归配置。

#### 绿灯：34条

绿灯进入 `【核心设定】` 区：

- `constant=false`
- `selective=true`
- `keys=[单一正则]`
- `secondary_keys=[]`
- `use_regex=true`
- `position=after_char`
- `prevent_recursion=true`
- `exclude_recursion=true`

绿灯必须双防递归，禁止由已注入绿灯正文继续触发其他绿灯形成链式点亮。

### 3.5 其他触发型业务条目

角色本体、角色能力、地点继续采用成熟全栈触发配置：

- `constant=false`
- `selective=true`
- `keys=[单一正则]`
- `secondary_keys=[]`
- `use_regex=true`
- `prevent_recursion=true`
- `exclude_recursion=true`

角色本体与角色能力：只扫描 `<story_scene>`。

地点：只扫描 `<status>` 中的 `当前位置:`。

禁止把关键词数组直接做成普通逗号列表；禁止角色/能力正则扫整段 status；禁止地点正则扫整篇剧情正文。

### 3.6 时间线

- 每卷/阶段时间线为完整 `<world_timeline>` 条目。
- 正文不混入 Markdown 标题、工程注释、迁移说明。
- 时间线位于输出规则区，使用 `at_depth` / depth=0 的全栈位置口径。
- 时间线不得全部同时 enabled。
- 默认只启用开局所需时间线，其余保持 disabled；切换由后续正式运行层按成熟机制处理。
- 事件编号继续使用 A / A1 / A2 / B / C 语义，不在装配时重写剧情事件编号。

### 3.7 输出规则与 MVU 系统条目

全栈最终整卡还包含：

- `变量输出格式`
- `变量列表`
- `变量更新规则`
- `[initvar]变量初始化勿开`

这四条属于 MVU/变量接线层，最终整卡不得遗漏；但在 MVU schema 尚未施工前，禁止凭空杜撰本卡变量正文。本轮业务世界书可以先完成骨架、蓝绿灯、角色、能力、地点与时间线；进入 MVU 阶段后必须从全栈空模板原样接入并按本卡真实 schema 填充，其中 initvar 保持 disabled。

## 4. 内生世界正文净化

正式 Character Book 的 `content` 只能包含世界内事实。

不得进入运行时正文的内容包括但不限于：

- 母卡 / 原卡 / 授权 / 迁移 / AU 对照说明
- 施工单、QA、职责、封版、build、runtime 等工程说明
- `# BLUE` / `# GREEN` / 灯色 / 上位蓝灯等工程头
- 对“高中版→大学版”“原作→派生版”的制作层解释

大学世界线、替身存在、人物身份与关系必须直接作为世界事实陈述。

## 5. MVU 边界

- MVU 不成为第二剧情真相源。
- 不在业务世界书里自造另一套状态容器、变量 API 或生命周期。
- `initvar / update / output / list` 四条按全栈空模板接线，不按旧卡或其他项目猜字段。
- initvar 保持 disabled，由 MVU 读取。

## 6. 历史坑拦截清单

以下问题任一出现，本轮世界书不得标记 PASS：

1. 蓝灯与绿灯职责混装或绿灯被常驻。
2. 蓝灯错误开启 `prevent_recursion` / `exclude_recursion`。
3. 绿灯未同时开启 `prevent_recursion=true` 与 `exclude_recursion=true`。
4. 角色本体与替身能力重新合并为一个条目。
5. 只装30名替身使者而漏掉14名非替身使者。
6. 触发关键词使用普通逗号列表而非单一 regex。
7. 角色/能力未限制在 `<story_scene>`；地点未限制在 `<status>` 的当前位置。
8. camelCase / snake_case 同义字段并存。
9. 七组分区14个起止标记缺失或重复。
10. `🗑️清空局部变量(别关)` 或三条记忆占位在最终整卡中漏装/误启用。
11. 工程说明、施工头、QA 文本进入运行时 `content`。
12. 多季时间线同时 enabled 导致上下文膨胀。
13. 时间线被拆成碎片或丢失 `<world_timeline>` 完整块。
14. 已封版的高阶替身形态被装配器提前解锁。
15. 旧高中世界线、未成年身份或旧反替身规则回灌。
16. 世界书与 MVU 各维护一套剧情/状态真相源。
17. 装配时擅自生成新角色、能力、地点或剧情事实。
18. 最终整卡漏掉变量输出格式、变量列表、变量更新规则或 disabled initvar。
19. 未经 QA 即把构建产物称为正式版或实机 PASS。

# 000 项目基线

## 项目

《辉夜大小姐想让我告白》角色卡 / 世界书 / 时间线 / MVU 扩展工程。

## 当前输入

- 原始输入：用户提供的 PNG 角色卡
- 原卡作者：咩咩
- 授权状态：用户说明已取得原卡使用/改编授权
- 当前策略：保留母版，先拆解后扩展，不直接重写成熟结构

## 冻结原则

1. `main` 为唯一正式基线。
2. 原始 PNG 母版不得覆盖、压缩、重编码或替换。
3. 原卡已有成熟咩咩结构时，优先复用，不自行另造平行体系。
4. 世界书、人物、地点、时间线、MVU 分层施工。
5. 每轮重大修改应留下可追溯 QA/施工记录。
6. 正式 Candidate 在完成结构 QA 后再生成。

## 初始施工顺序

1. 原卡拆解与字段审计
2. 原卡世界书 / 角色 / 开场 / 状态结构基线冻结
3. 蓝灯核心设定
4. 绿灯展开设定
5. 主要人物与关系
6. 地点 / 组织
7. 原作时间线
8. MVU
9. QA 与 Candidate

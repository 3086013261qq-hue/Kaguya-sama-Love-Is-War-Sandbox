# 秀知院大学世界线迁移规则 v1.0

## 目的

本工程不再以原作高中阶段作为运行时舞台，而采用独立的“秀知院大学世界线”。原授权母卡仅作为事实、人物性格、关系、事件与文本结构来源；正式世界书、人物条目、时间线与开场均按大学世界线重映射。

## 总体原则

1. 所有具名学生角色在本世界线中均为成年人，最低年龄 18 岁。
2. 原作人物的相对年龄差、前后辈关系、兄弟姐妹关系、学生会职务关系尽量保持不变。
3. 原作的恋爱喜剧、人际关系、性格、心理机制、对话风格和事件因果优先保留；凡依赖“高中/初中/未成年身份”的表述，统一迁移为大学世界线的等价表述。
4. 原卡母版不改写、不覆盖；迁移内容只写入派生目录。
5. 后续所有正式运行时内容以本文件为最高年龄与学段基准，不得回退到未成年校园设定。

## 年级映射

- 原作初三 → 大学一年级
- 原作高一 → 大学二年级
- 原作高二 → 大学三年级
- 原作高三 → 大学四年级

若出现更低年级具名学生，则不机械保留原学段，统一迁移为年满 18 岁的大学一年级或与其原相对年龄关系相符的成年阶段。

## 舞台映射

- 秀知院学园高中部 → 秀知院大学
- 高中学生会 → 秀知院大学学生会
- 教室/年级班级 → 学部课程班/研讨课/共同教养课程
- 社团活动 → 大学社团、研究会、学园祭执行组织
- 放学后 → 下课后/晚课后/社团活动后
- 文化祭 → 秀知院大学学园祭
- 体育祭 → 校园体育祭/大学运动会
- 修学旅行 → 大学研修旅行/学术交流旅行

## 升学映射

原作中“考大学、志愿校、升学、保送”等剧情功能整体上移：

- 考大学 → 考研究生
- 大学志愿 → 研究生院/研究科志愿
- 推荐入学/保送 → 推免/内部推荐升学
- 升学咨询 → 研究生升学咨询
- 模拟考试 → 考研模拟/院试准备
- 留学升学 → 海外研究生院申请/交换与深造

因此，大四角色面临研究生院、就业、留学等选择；大三角色开始进入考研、实习、科研与未来规划阶段。

## 人物核心映射

- 四宫辉夜、白银御行、藤原千花等原高二核心成员 → 大三
- 石上优、伊井野弥子等原高一成员 → 大二
- 原高三成员 → 大四
- 白银圭等原初三成员 → 大一

具体年龄在人物精修阶段逐人确定，但不得低于 18 岁。

## 文本迁移规则

可直接保留：
- 性格与心理模型
- 恋爱关系与误会机制
- 家族背景与阶层关系
- 对话风格与口癖
- 事件的因果、笑点、胜负结构
- 成年角色的外貌与身体特征字段

必须替换：
- 高中生/初中生身份
- 高中/初中年级
- 未成年相关限制与监护语境
- 高考/大学志愿等升学名词
- 依赖原校园制度的班级、课程与活动名称

## 运行时硬规则

正式卡中不得出现与本世界线冲突的“未成年学生”回退。若原卡文本或时间线残留旧学段词汇，AI必须优先按本规则解释并自动转换为大学世界线等价物，而不是恢复原作年龄。

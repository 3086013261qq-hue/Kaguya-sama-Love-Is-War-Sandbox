# Worldbook

本目录保存《辉夜大小姐想让我告白》秀知院大学版世界书工程。

正式运行内容遵循“内生世界描述”原则：模型能够看到的 Character Book 正文只描述这个世界本身存在的人物、地点、制度、历史与规则，不包含原卡来源、改编过程、迁移说明、AU标签、施工要求或QA备注。

目录约定：

- `core/`：可读的世界基础设定，内容必须使用内生世界叙述。
- `final/`：83条世界书的模块化构建输入与组装器。
- `final/assemble_worldbook.py`：正式组装入口；负责保持ID/order/enabled/regex结构，同时剥离制作层标签并输出最终 Character Book。
- 原卡拆解、授权来源、迁移映射与施工记录统一保存在 `source/`、`docs/` 与 `qa/`，不得作为世界书正文注入模型。

结构仍采用蓝灯总则 + 绿灯展开：全局世界规则保持精炼常驻，人物、地点、组织与事件细节按触发条件展开。

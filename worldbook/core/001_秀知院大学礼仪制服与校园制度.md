# 秀知院大学礼仪制服与校园制度

本条是“秀知院大学世界线”的视觉与校园制度兼容规则。

- 秀知院大学作为历史悠久的顶级私立名门，在大学阶段仍保留正式的礼仪制服制度；礼仪制服主要用于学生会、正式课程、校内仪式、学园祭、社团公开活动与需要统一着装的场合。
- 原卡中具有角色辨识度的制服、发饰、鞋袜、学生会袖章等视觉锚点原则上保留；其中“高中制服 / 初中制服 / 中等部制服 / 学园制服”等身份性称呼，运行时统一解释为相应大学年级的礼仪制服。
- 日常非正式课程、社团活动、校外约会、打工、研究与实习场景允许角色穿私服，不强制全天候制服化。
- 原作的学生会、风纪委员、媒体部、桌游部、社团与委员会体系在本世界线中作为秀知院大学特有的传统自治组织继续存在。
- 原作“放学”统一迁移为“下课 / 晚课后 / 社团活动后”；“校规”按大学校纪与自治条例解释；文化祭按秀知院大学学园祭解释；体育祭按大学运动会解释。
- 该规则只迁移舞台与制度，不改变角色性格、关系、恋爱喜剧机制、外貌锚点与原事件的核心因果。

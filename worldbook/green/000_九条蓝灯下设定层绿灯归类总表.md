# 九条蓝灯下设定层绿灯归类总表

<设定层绿灯归类>
本表只整理世界设定层绿灯，不包含人物、地点、时间线、输出规则、记忆运行时与具体角色替身分配。

当前结构：9条蓝灯 + 34条设定层绿灯。

## 蓝灯01｜世界基调｜天才们的恋爱战争
正式绿灯：
1. `01-01｜秀知院大学礼仪制服与着装文化`
2. `01-02｜秀知院大学校园传统与公共活动`
3. `01-03｜替身梗化日常与校园便利`

职责：校园日常气质、传统、着装，以及替身进入学习、社团、学生会、打工与恋爱生活后的日常用法和喜剧化表现。替身可以成为生活工具，但不能突破自身固有机制。

## 蓝灯02｜学籍、年龄与校园身份法则
正式绿灯：
1. `02-01｜秀知院大学课程体系与学业竞争`
2. `02-02｜秀知院大学学生会结构与自治权限`
3. `02-03｜秀知院大学社团与研究会体系`
4. `02-04｜校园异常事件与学生会善后`

职责：大学学业、学生自治、社团体系，以及替身异常发生在校园后由学生会、校方、保安、医务与学生组织承担的现实善后。

## 蓝灯03｜现实社会、财富与阶层法则
正式绿灯：
1. `03-01｜金钱、物价与生活成本`
2. `03-02｜财阀资源与社会影响`
3. `03-03｜替身事故责任、赔偿与现实后果`
4. `03-04｜财阀对替身现象的调查与资源化`

职责：现实社会仍存在账单、赔偿、医疗、法律与组织成本；财阀可以调查、招揽、监视和利用替身使者，但不能凭资源自动破解能力、购买忠诚或抹除真实后果。

## 蓝灯04｜替身存在与替身使者法则
正式绿灯：
1. `04-01｜替身性能六维与射程原则`
2. `04-02｜替身类型、形态与操纵方式`
3. `04-03｜本体关联、伤害反馈与存续`
4. `04-04｜普通人目击、影像与异常痕迹`
5. `04-05｜伤势、医疗、恢复与长期影响`

职责：替身的性能、存在形态、本体关联与现实可观测后果。普通人通常看不见替身本体，但能看到现实后果；替身战造成的伤势和医疗后果连续存在。

## 蓝灯05｜情感能源法则
正式绿灯：
1. `05-01｜复合情感与主导情绪`
2. `05-02｜情感持续、压抑与消退`

职责：真实情感的横向复合结构与纵向持续结构。真实情感始终是活着的替身使者推动替身发挥的唯一驱动力；不建立精神力、觉悟值、决意值、情绪槽、固定倍率或第二能源。

## 蓝灯06｜情感波动与增幅法则
正式绿灯：
1. `06-01｜情感刺激与真实响应`
2. `06-02｜情感增幅的战术、误判与反噬`
3. `06-03｜情感峰值与能力增幅边界`

职责：外界刺激如何改变真实情感，以及这种变化怎样影响替身发挥。告白、嫉妒、恐惧、愤怒与欲望可以形成峰值，但只能增幅既有机制，不能自动创造新能力或特殊进化。

## 蓝灯07｜替身适配与觉醒法则
正式绿灯：
1. `07-01｜替身资质与自然觉醒`
2. `07-02｜初次显现与能力认知`
3. `07-03｜替身成长、阶段变化与特殊进化`
4. `07-04｜觉醒后适应、训练与误用`

职责：资质、觉醒、初次掌握、训练、误用、一般成长与少数替身的固有阶段变化。训练提高熟练度和理解，不会直接刷出高阶形态。

## 蓝灯08｜颅内剧场即替身战法则
正式绿灯：
1. `08-01｜颅内剧场表现层与现实映射`
2. `08-02｜能力解谜与情报战`
3. `08-03｜本体、媒介与发动条件攻防`
4. `08-04｜校园环境、无辜者与战场约束`
5. `08-05｜替身秘密暴露与长期情报差`

职责：真实替身战的表现、解谜、条件攻防，以及校园环境、普通人和长期情报连续性。已经确认过的能力规则不会在下一场景自动失忆。

## 蓝灯09｜恋爱头脑战与表白原则
正式绿灯：
1. `09-01｜先后手、诱导与情感暴露`
2. `09-02｜多层胜负与关系后果`
3. `09-03｜替身介入恋爱秘密与隐私边界`
4. `09-04｜公开告白、校园传闻与社交扩散`

职责：自尊、主动权、情感暴露、关系后果，以及替身介入恋爱信息与校园舆论后的隐私、信任和社会压力。能力可以帮助获取事实，却不能把爱、忠诚、承诺与同意直接变成能力结果。

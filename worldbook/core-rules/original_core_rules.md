## 秀知院学园课程体系
介绍：以培养未来国家栋梁、财阀继承人及各界精英为目标的综合教育体系。在符合常规高中的教育标准基础上，融入大量难度极高的学术内容与贵族素养培育项目。
基础学科分类：
- 核心文化课：包含高标准的国语、数学、英语、理科（物理、化学、生物）与社会科（日本史、世界史、地理、现代社会等）。教学进度快，教材难度远超普通高中。
- 国际外语课：除英语必修外，提供第二外语选修。由于现任校长具有法国背景，法语是学校的重要交流语言之一，也设有专门的法语课程与国际交流活动。
素养与技能课程：
- 体育课程：除了常规的田径、体操、球类与游泳，还设有专门的社交舞课程、剑道课程，部分校区及社团涉及马术等贵族运动。
- 艺术与家政：提供正统的传统文化教养（如茶道、花道）、古典音乐欣赏、美术，以及包含高级烹饪与餐桌礼仪在内的家政课程。
考核与竞争机制：
- 定期测验：每学期举行严格的期中与期末考试，考场纪律森严。
- 成绩公示榜：每次大型考试结束后，全校总成绩排名前50名的学生名单与具体分数会被公开张贴在走廊的巨型布告栏上，校内竞争氛围极为激烈。
- 学业压力：无论是初中部直升的“纯院”贵族学生，还是凭借高分考入的“混院”平民学生，最终都必须以学业成绩作为衡量个人在校内地位的重要指标。
</秀知院学园课程>

## 秀知院学生会结构
介绍：秀知院学园的最高学生自治组织，拥有极高的实际权力与威望。负责统筹学园内所有的学生活动、社团预算分配以及日常纪律监督，历代学生会成员多为学园内的顶尖精英。
核心职位分配：
- 会长：学生会的最高决策者，负责总体方向把控与各项文件的最终审批。拥有极高的话语权，通常由极具领导力与声望的学生担任。
- 副会长：仅次于会长的二把手，协助会长处理繁杂事务，在会长缺席或忙碌时暂代其职权，协调会内工作。
- 书记：主要负责会议记录、文件整理归档、对外联络以及学生会的各项文书与公共关系工作。
- 会计：掌管学生会的财政大权，负责处理日常财务、制作收支报表、审核各社团的预算申请单，控制资金流向。
- 会计稽查：负责审查会计账目，监督学生会及各个社团的资金使用情况是否违规，同时通常兼顾校园风纪的巡视与纠察工作。
运作与职权机制：
- 换届选举：每年定期举行，通过全校学生投票产生新一届学生会会长，随后由新任会长直接指派或招募其他核心干部。
- 预算决定权：掌握学园资源的绝对分配权，能够直接通过预算审批决定社团的存续、活动规模以及特殊设施的采购。
- 统筹决议：主导并策划学园内所有大型公共活动，包括但不限于体育祭、奉心祭（文化祭）以及修学旅行的各项筹备。
</秀知院学生会结构>

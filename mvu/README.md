# MVU

当前正式设计方向：**极简片尾判定牌 MVU**。

本模块不承担剧情推进、不复制世界书状态、不做多页仪表盘。

唯一业务变量：

- `today_verdict`：记录最新一次真正结算后的《辉夜大小姐》式片尾判定，例如“今日，是四宫辉夜的败北。”

UI只保留：

1. `本日の勝敗`片尾判定牌；
2. 单曲混音主题曲播放器。

正式设计稿：

- `mvu/001_极简片尾判定MVU设计_v0.1.md`

技术底座：咩咩制卡·全栈 v1.0.0 原生 MVU 九件套；不修改咩咩预设，不自造第二套 MagVarUpdate / registrar / 状态容器。

主题曲准确文件名当前尚未进入仓库；正式音频接入后登记至 `mvu/media-manifest.v1.json`。
